1. The Anatomy of a Linear Program (LP)

Linear Programming is a mathematical tool used to find the "best" outcome (such as maximum profit or lowest cost) in a given mathematical model [1].

Decision Variables

The quantities you control.
Ex: How many trucks (x1) and trains (x2) to build [1].

Objective Function

What you want to optimize.
Ex: Maximize Profit (z = 450x1 + 550x2) [2].

Constraints

The "rules" or limits.
Ex: Carpentry labor cannot exceed 5000 hours [3].

Example: The Pinocchio, Inc. Model [3]

A toy maker needs to decide production levels under limited resources:

Maximize z = 450x1 + 550x2 (Profit)
Subject to:
x1 + 2x2 ≤ 5000 (Carpentry)
x1 + x2 ≤ 3000 (Finishing)
x1 ≤ 2000 (Truck Demand)
x1, x2 ≥ 0 (Nonnegativity)

2. Visualizing Solutions (Graphical Method)

If a problem has only two variables, we can "draw" the solution [3].

Step 1: The Feasible Area

The shaded region on a graph where all constraints overlap. Every point in this region is a "possible" solution [4].

Step 2: The Optimal Solution

According to the Basic LP Theorem, the best solution will always be at a corner point of the feasible area [5].

Optimal Corner Point for Pinocchio:
x1=1000, x2=2000
Max Profit: 1,550,000 CZK [5]

3. Sensitivity Analysis: "What If?"

Management science isn't just about the answer; it's about how the answer changes if the world changes [6].

  • Binding Constraints: Resources you used up completely (Zero Slack). If you had more, your profit would go up [6].
  • Slack Variables: Represent unused resources (e.g., leftover labor hours) [6].
  • Surplus Variables: How much you exceeded a minimum requirement (e.g., building 1000 units when demand was only 600) [6].

5. Network Modeling

Managerial problems can be visualized as nodes (circles) and arcs (lines) [13].

Network Terminology

  • Nodes: Represent cities, junctions, or objects [13].
  • Arcs: Represent roads, pipes, or relationships (can be directed/one-way) [13].
  • Path: A sequence of arcs connecting nodes [13].
  • Circuit: A path that starts and ends at the same node [13].
NETWORK MAP:
(1) ---- [arc] ---- (2)
| \ / |
| \ (4) [arc] / |
| / \ |
(3) ---- [arc] ---- (6)

Game: The Shortest Path Quest

Goal: Find the path between Node 1 and Node 6 with the lowest "cost" or distance [14].

Imagine Node 1 is a warehouse and Node 6 is a customer. This is the foundation of modern GPS routing!

Watch Out: Special Solution Cases

Alternative Optima

When there is more than one "best" way to get the same maximum profit [15].

Infeasibility

When the rules are too strict and no solution exists that follows all of them [16].

Unboundedness

When the profit could technically go to infinity (usually means you forgot a constraint!) [16].
